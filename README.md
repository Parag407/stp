# Silver TC Fitting

A React + Vite website for Silver TC Fitting, a manufacturer and supplier of high-quality pipes, valves, and fittings for dairy, pharmaceutical, and industrial sectors.

## Tech Stack

- **React 19** with Vite
- **Tailwind CSS v4**
- **React Router DOM v7**

## Pages

- **Home** — Carousel slider, features, featured products, brands marquee
- **About** — Company story, stats, CTA
- **Products** — Category filters, paginated product grid, product detail view
- **Quality** — Quality standards, services grid
- **Contact** — Contact form, phone/email with copy, Google Map

## Features

- Responsive design (mobile-first)
- Animate on scroll (4 variants: fade-up, fade-left, fade-right, scale)
- Page transitions
- Product filtering and pagination
- Brand scrolling marquee
- Quotation modal
- Copy-to-clipboard for phone/email

## Getting Started

```bash
npm install
npm run dev
```

Build: `npm run build`
Preview: `npm run preview`
